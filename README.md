# Gap Analysis de Ciberseguridad y Riesgo Tecnológico — Banco del Lago, S.A.

**Caso de estudio ficticio** que aplica el NIST CSF 2.0 e ISO/IEC 27001:2022 a una institución financiera guatemalteca construida con datos reales del mercado. El objetivo es demostrar la metodología completa de un Gap Analysis: evaluación de madurez, identificación de brechas, y plan de remediación con ROI.

> **Nota:** Banco del Lago, S.A. es ficticio. Los resultados (madurez 1.7/5.0, 40 hallazgos, Q1,330,000 de inversión) corresponden exclusivamente a este caso de estudio y **no representan el estado real de la banca guatemalteca**. Es un ejercicio de aplicación de metodología.
